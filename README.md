## How to run
1. `python -m venv .venv` / activate
2. `pip install -r requirements.txt`
3. `cp .env.example .env`   (set LLM_PROVIDER=<provider>)
4. `python src/rag/ingest.py`   (build the index)
5. `python src/app.py`          (start the app)
